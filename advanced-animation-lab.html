02 Canvas & requestAnimationFrame

Canvas API vẽ trực tiếp lên bitmap — phù hợp cho particle systems, game loops, và generative art. requestAnimationFrame đồng bộ với browser refresh (60fps). Performance tốt hơn DOM cho số lượng lớn objects.

particle system
ripple wave
noise field
rAF game loop
0 fps
// game loop pattern
function loop(timestamp) {
  ctx.clearRect(0, 0, w, h);      // clear
  particles.forEach(p => {
    p.x += p.vx; p.y += p.vy;  // update
    draw(p);                    // render
  });
  requestAnimationFrame(loop);  // queue next
}
requestAnimationFrame(loop);     // start
// sine wave — Math.sin(x + time) × amplitude
for (let x = 0; x < w; x++) {
  const y = h/2 + Math.sin((x * freq) + t) * amp;
  // thêm nhiều wave với freq/phase khác nhau
    + Math.sin((x * freq * 2) + t * 1.5) * amp * 0.5;
}
// flow field dùng sin/cos để simulate Perlin noise
const angle = Math.sin(x * 0.01) * Math.cos(y * 0.01) * t;
particle.vx = Math.cos(angle) * speed;
particle.vy = Math.sin(angle) * speed;
requestAnimationFrame
Browser gọi callback trước mỗi repaint (~16.67ms ở 60fps). Tự động throttle khi tab không active. Luôn pass timestamp để tính delta time.
setInterval / setTimeout
Không sync với browser refresh → có thể chạy giữa frame → visual tearing, jank. Chỉ dùng cho logic, không dùng cho visual animation.
Delta time pattern
Dùng (timestamp - prevTime) / 1000 để tính delta giây — animation speed không phụ thuộc frame rate của máy người dùng.
Canvas vs DOM
Canvas tốt hơn cho 100+ objects cùng lúc. DOM + CSS tốt hơn cho <50 objects có interaction phức tạp. WebGL (Three.js) cho 10,000+.
let prev = 0;
function loop(ts) {
  const dt = (ts - prev) / 1000;  // delta giây
  prev = ts;
  x += speed * dt;            // dt-based movement
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);

Scene Graph
Cây phân cấp objects. Child inherit transform từ parent. Dùng Group để nhóm và animate tập thể.
Camera types
PerspectiveCamera — realistic, fov-based. OrthographicCamera — flat, không perspective. Dùng Perspective cho 3D scenes.
Lights
AmbientLight — fill. DirectionalLight — sun. PointLight — bulb. MeshBasicMaterial không cần light.
Performance
Dispose geometry/material khi không dùng. Minimize draw calls. Dùng InstancedMesh cho nhiều objects giống nhau.
Resize handling
Cần update camera.aspect, camera.updateProjectionMatrix(), và renderer.setSize() khi resize.
React Three Fiber
@react-three/fiber — React wrapper cho Three.js. JSX syntax, hooks, automatic resize. Dùng cho React projects.
// resize handler — bắt buộc
window.addEventListener('resize', () => {
  camera.aspect = w / h;
  camera.updateProjectionMatrix();
  renderer.setSize(w, h);
  renderer.setPixelRatio(Math.min(devicePixelRatio, 2));
});

06 Framework Integration

Mỗi framework có cách tích hợp animation riêng — React cần cleanup, Next.js cần handle SSR, Vue có transition system built-in. Pattern cốt lõi: animate sau khi DOM sẵn sàng, cleanup khi component destroy.

Next.js SSR
Vue transitions
patterns & pitfalls
useGSAP hook (recommended)
Official hook từ @gsap/react. Auto cleanup, Strict Mode safe, scoped selectors.
gsap.context() + useEffect
Bọc tất cả GSAP calls trong context. return ctx.revert() trong cleanup.
❌ gsap.to() trực tiếp trong render
Tạo tween mỗi render cycle → memory leak. Không bao giờ call GSAP ngoài useEffect/useGSAP.
❌ Thiếu cleanup
Tween không bị kill khi unmount → animation zombie chạy trên DOM đã xoá → lỗi.
// ✅ useGSAP — pattern chuẩn nhất
import { useGSAP } from '@gsap/react';
useGSAP(() => {
  gsap.from('.card', { y:30, opacity:0, stagger:.1 });
  // không cần return cleanup
}, { scope: containerRef, dependencies: [data] });
SSR — window is undefined
GSAP, Three.js, và nhiều animation libs cần window. Dùng dynamic import hoặc check typeof window !== 'undefined'.
✅ dynamic import
const gsap = (await import('gsap')).gsap trong useEffect — đảm bảo chỉ load client-side, không break SSR.
✅ 'use client' directive
Mark component là client-only với 'use client' ở đầu file. Toàn bộ component tree sẽ render client-side.
Page transitions
Dùng Framer Motion với App Router: wrap layout với AnimatePresence, dùng key=pathname để trigger exit/enter.
'use client';                     // Next.js App Router
import { useGSAP } from '@gsap/react';
// hoặc dynamic import trong useEffect:
useEffect(() => {
  const load = async () => {
    const { gsap } = await import('gsap');
    gsap.from('.hero', { y:40, opacity:0 });
  };
  load();
}, []);
✅ <Transition> component
Vue built-in: tự động thêm CSS classes v-enter-active, v-leave-active. Tốt cho show/hide đơn giản.
✅ onMounted lifecycle
Tương đương useEffect. GSAP/WAAPI chỉ chạy sau onMounted đảm bảo DOM đã render.
@vueuse/motion
Motion directives cho Vue: v-motion, :initial, :enter, :leave — syntax giống Framer Motion.
GSAP trong Vue
Dùng onMounted(() => { ... }) + onUnmounted(() => ctx.revert()). Không có useGSAP hook như React nhưng pattern tương tự.
// Vue 3 Composition API + GSAP
import { onMounted, onUnmounted, ref } from 'vue';
const el = ref(null);
let ctx;
onMounted(() => {
  ctx = gsap.context(() => {
    gsap.from(el.value, { y:30, opacity:0 });
  });
});
onUnmounted(() => ctx.revert());
✅ Animate sau DOMContentLoaded
Hoặc trong lifecycle hook. Elements phải exist trong DOM trước khi GSAP tìm chúng.
❌ String selector trong React
gsap.to('.box', ...) trong React tìm tất cả .box trên page, không phải chỉ trong component. Dùng scope hoặc ref.
✅ prefers-reduced-motion
gsap.matchMedia() để conditional animation. useReducedMotion() trong Framer Motion. Accessibility từ đầu.
❌ Heavy animation on main thread
Chỉ animate transform và opacity. Canvas và WebGL cho heavy visuals. Tránh JS animation cho layout properties.
✅ Code splitting
Lazy load animation libraries. GSAP plugins đặc biệt nặng — chỉ import khi cần: await import('gsap/ScrollTrigger').
❌ Không test trên mobile
60fps trên desktop → 30fps trên mid-range mobile. Luôn test trên device thực. Tắt animation phức tạp khi navigator.hardwareConcurrency < 4.
// prefers-reduced-motion — GSAP matchMedia
const mm = gsap.matchMedia();
mm.add('(prefers-reduced-motion: no-preference)', () => {
  gsap.from('.hero', { y:60, opacity:0, duration:1 });
  return () => {};  // cleanup
});
07 Advanced Best Practices

Picking the right tool, performance at scale, và mental models cho production animation.

chọn đúng tool
performance at scale
accessibility
/* Decision tree: */
// Hover, transition đơn giản? → CSS
// React UI micro-interactions? → Framer Motion
// Complex timeline + scroll? → GSAP
// 1000+ objects / game? → Canvas / WebGL
// 3D? → Three.js
// Designer-made animations? → Lottie
// No library + basic control? → WAAPI
Measure first
Chrome DevTools Performance tab → record → tìm long tasks > 50ms. Đừng optimize trước khi đo.
60fps = 16.6ms/frame
Browser cần <10ms để paint. Giữ JS work <6ms/frame. Batch DOM reads, không xen kẽ read/write.
GPU layers
will-change: transform trước animation phức tạp. Remove sau khi xong. Tránh layer explosion.
Code splitting
Lazy load Three.js, GSAP plugins. Bundle size ảnh hưởng Time-to-Interactive — animation không chạy trước khi load xong.
Intersection Observer
Pause animation khi element ra khỏi viewport. Đặc biệt quan trọng với Canvas và Three.js — save GPU/CPU.
OffscreenCanvas
Move Canvas rendering sang Web Worker — unblock main thread. Supported Chrome/Firefox, fallback gracefully.
// pause Three.js khi tab không active
document.addEventListener('visibilitychange', () => {
  document.hidden ? renderer.setAnimationLoop(null) : renderer.setAnimationLoop(loop);
});
// pause Canvas khi ra viewport
const obs = new IntersectionObserver(([e]) => {
  e.isIntersecting ? startLoop() : stopLoop();
});
obs.observe(canvas);
prefers-reduced-motion
Media query bắt buộc. Disable hoặc simplify tất cả decorative animations. Keep essential feedback animations (loading, progress).
ARIA live regions
Animation thay đổi content → aria-live="polite" để screen reader thông báo. Toast notifications, counters, status updates.
Flashing content
WCAG 2.3.1: không flash nhiều hơn 3 lần/giây. Người dùng bị epilepsy có thể bị kích hoạt. Dùng Photosensitive Epilepsy Analysis Tool.
Parallax & vestibular
Scroll parallax gây chóng mặt cho người có vestibular disorders. Disable khi prefers-reduced-motion: reduce.
Focus management
Modal open animation → move focus vào modal. Modal close → return focus về trigger. Framer Motion AnimatePresence cần manual focus management.
Test với real users
Automated checks không bắt được hết accessibility issues. Test với VoiceOver (Mac/iOS), NVDA (Windows), TalkBack (Android).
/* WCAG-compliant animation pattern */
@media (prefers-reduced-motion: reduce) {
  *,*::before,*::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
