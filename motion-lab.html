01 motion component — animate, initial, exit

motion.div, motion.span, motion.button... là wrapper của HTML elements. Ba prop cốt lõi: initial (trạng thái bắt đầu), animate (trạng thái đích), transition (cấu hình animation). Đây là building block của mọi animation trong Framer Motion.

initial & animate
transition config
whileAnimate states
keyframes
// motion.div thay vì div — thêm animation superpowers
<motion.div
  initial={{ opacity: 0, y: 30, scale: 0.8 }}
  animate={{ opacity: 1, y: 0, scale: 1 }}
  transition={{ duration: 0.6, ease: 'easeOut' }}
/>
// transition types: tween (CSS-like), spring (physics), inertia
transition={{ type: 'spring', stiffness: 260, damping: 20 }}
transition={{ type: 'tween', duration: 0.4, ease: 'easeInOut' }}
transition={{ delay: 0.2, repeat: Infinity, repeatType: 'mirror' }}
// animate thay đổi khi state thay đổi — Motion re-animate tự động
const [active, setActive] = useState(false);
<motion.div
  animate={{ scale: active ? 1.3 : 1, backgroundColor: active ? '#8b5cf6' : '#1f1f34' }}
  onClick={() => setActive(!active)}
/>
// keyframes: array values — Motion tự interpolate
animate={{ x: [0, 100, 50, 150], rotate: [0, 45, -10, 0] }}
transition={{ duration: 2, times: [0, 0.3, 0.7, 1] }} // times = % mốc
02 Variants & Orchestration

variants là named animation states — thay vì inline objects, bạn định nghĩa một lần rồi dùng lại bằng tên. Sức mạnh thực sự là orchestration: parent variant tự động propagate xuống children, kèm staggerChildren, delayChildren, when.

variants cơ bản
staggerChildren
when & orchestration
propagation
const variants = {
  hidden: { opacity: 0, y: 20 },
  visible: { opacity: 1, y: 0 },
};
<motion.div variants={variants} initial="hidden" animate="visible" />
const container = {
  hidden: {},
  visible: { transition: { staggerChildren: 0.1, delayChildren: 0.2 } }
};
const item = {
  hidden: { opacity: 0, y: 20 },
  visible: { opacity: 1, y: 0 }
}; // children TỰ ĐỘNG nhận stagger từ parent
// when: "beforeChildren" | "afterChildren"
const container = {
  hidden: { opacity: 0 },
  visible: { opacity: 1, transition: {
    when: "beforeChildren",    // parent fade in TRƯỚC
    staggerChildren: 0.12
  } }
};
// propagation: parent animate="visible" → truyền xuống tất cả children
// children không cần initial/animate riêng — kế thừa từ parent
<motion.ul initial="hidden" animate="visible" variants={container}>
  {items.map(i => <motion.li variants={item}>{i}</motion.li>)}
</motion.ul>
03 AnimatePresence — exit animations

React unmount element ngay lập tức — AnimatePresence giữ element lại đủ lâu để chạy exit animation. Dùng cho modal, list items, page transitions. mode prop kiểm soát thứ tự enter/exit.

exit animation
list add/remove
mode: wait
page transitions
// AnimatePresence: detect unmount → chạy exit trước khi xoá
<AnimatePresence>
  {isVisible && (
    <motion.div
      initial={{ opacity:0, scale:0.8 }}
      animate={{ opacity:1, scale:1 }}
      exit=  {{ opacity:0, scale:0.5 }} // chạy khi unmount
    />
  )}
</AnimatePresence>
// key prop bắt buộc để AnimatePresence track từng item
<AnimatePresence>
  {items.map(item => (
    <motion.div key={item.id}              // KEY quan trọng!
      initial={{ opacity:0, height:0 }}
      animate={{ opacity:1, height:'auto' }}
      exit=  {{ opacity:0, height:0 }}
    />
  ))}
</AnimatePresence>
// mode="wait": exit xong rồi mới enter — tránh overlap
// mode="sync" (mặc định): enter và exit chạy cùng lúc
// mode="popLayout": exit xong + layout reflow rồi mới enter
<AnimatePresence mode="wait">
  <motion.div key={currentPage} ...transitions/>
</AnimatePresence>
// page transitions: key=route, exit animate ra rồi new page animate vào
<AnimatePresence mode="wait">
  <motion.div key={pathname}
    initial={{ x:'100%', opacity:0 }}
    animate={{ x:0, opacity:1 }}
    exit=  {{ x:'-100%',opacity:0 }}
  />
</AnimatePresence>
04 Motion Hooks — useScroll, useTransform, useSpring

Hooks cho phép đọc và transform animation values imperatively. useMotionValue là reactive value, useTransform map một range sang range khác, useSpring thêm spring physics, useScroll đọc scroll position.

useMotionValue
useTransform
useSpring
useScroll
// useMotionValue: reactive value — cập nhật không trigger re-render
const x = useMotionValue(0);
// đọc: x.get() | ghi: x.set(100) | subscribe: x.on('change', cb)
<motion.div style={{ x }} />  // bind trực tiếp vào style
// useTransform: map input range → output range
const x = useMotionValue(0);
const opacity = useTransform(x, [-200, 0, 200], [0, 1, 0]);
const rotate = useTransform(x, [-200, 200], [-30, 30]);
const scale = useTransform(x, [-200, 0, 200], [0.7, 1, 0.7]);
// useSpring: wrap MotionValue với spring physics
const mouseX = useMotionValue(0);
const springX = useSpring(mouseX, { stiffness:300, damping:30 });
// khi mouseX thay đổi, springX "đuổi theo" với spring physics
<motion.div style={{ x: springX }} />
// useScroll: đọc scroll progress (0 → 1)
const { scrollYProgress } = useScroll();
const scaleX = useSpring(scrollYProgress, { stiffness:100, damping:30 });
// containerRef: scroll trong container, không phải window
const { scrollYProgress } = useScroll({ container: containerRef });
05 Gestures — hover, tap, drag, pan

Framer Motion có gesture system built-in: whileHover, whileTap, whileDrag là shorthand animate states khi gesture active. drag prop biến element thành draggable với physics và constraints.

whileHover & whileTap
drag
dragConstraints
useDragControls
// whileHover / whileTap: animate state khi gesture active
<motion.button
  whileHover={{ scale:1.05, y:-3 }}
  whileTap= {{ scale:0.95 }}
  transition={{ type:'spring', stiffness:400, damping:17 }}
>Click me</motion.button>
// drag="x"|"y"|true — cho phép kéo theo trục
<motion.div
  drag                             // drag cả 2 trục
  dragElastic={0.1}              // độ đàn hồi khi ra ngoài bounds
  dragMomentum={true}            // inertia khi thả
  whileDrag={{ scale:1.1, zIndex:10 }}
/>
// dragConstraints: giới hạn vùng drag
const constraintRef = useRef(null);
<div ref={constraintRef}>
  <motion.div drag dragConstraints={constraintRef} />
</div>
// hoặc object: dragConstraints={{ top:0, left:0, right:200, bottom:200 }}
// useDragControls: trigger drag từ element khác (e.g. handle)
const controls = useDragControls();
<div onPointerDown={e => controls.start(e)}>⠿ drag handle</div>
<motion.div drag dragControls={controls} />
06 Layout Animations — layout, layoutId, LayoutGroup

layout prop tự động animate khi element thay đổi kích thước hoặc vị trí trong DOM. layoutId tạo shared layout transitions giữa hai component khác nhau — đây là tính năng ấn tượng nhất của Framer Motion mà GSAP không có built-in.

layout prop
layoutId shared
LayoutGroup
list reorder
// layout: tự động detect DOM position change → animate
// không cần biết từ đâu đến đâu — Motion tự tính (FLIP technique)
<motion.div layout>...</motion.div>
// layout="position": chỉ animate position, không animate size
// layout="size": chỉ animate size
// layout="preserve-aspect": giữ tỉ lệ khi scale
// layoutId: "magic motion" giữa 2 component KHÁC NHAU
// Motion nhận ra cùng layoutId và animate giữa chúng
{!expanded && <motion.div layoutId="card" />}  // thumbnail
{expanded && <motion.div layoutId="card" />}  // modal full
// Motion tự animate thumbnail → modal và ngược lại
// LayoutGroup: sync layout animations giữa các components riêng
// khi một item expand, các item khác tự động reflow có animation
<LayoutGroup>
  {items.map(i => <AccordionItem key={i.id} />)}
</LayoutGroup>
// Reorder list: Reorder.Group + Reorder.Item
<Reorder.Group values={items} onReorder={setItems}>
  {items.map(i => (
    <Reorder.Item key={i} value={i}>{i}</Reorder.Item>
  ))}
</Reorder.Group>
07 Best Practices & Common Pitfalls

Những lỗi hay gặp, performance tips, và mental models khi dùng Framer Motion trong React project thực tế.

dos & don'ts
performance
vs GSAP
✅ Dùng variants cho reusable
Định nghĩa variants ngoài component tránh re-create object mỗi render. Đặt trong file riêng và import — dễ maintain và test.
❌ Inline object trong animate
Tránh animate={{ x: computed }} với object mới mỗi render — gây re-animation không cần thiết. Dùng useMotionValue hoặc animate với stable reference.
✅ AnimatePresence đúng vị trí
AnimatePresence phải bao trực tiếp conditional render. Component bên trong phải có key prop unique để Motion track được.
❌ Quên key trong AnimatePresence
Không có key → Motion không biết element nào unmount → exit animation không chạy. Key phải là unique identifier, không phải index.
✅ useReducedMotion
Dùng hook useReducedMotion() để detect preference và disable/simplify animations. Accessibility-first từ đầu.
❌ Layout animation không cần thiết
layout prop dùng FLIP technique — tốn CPU mỗi render. Chỉ dùng khi thực sự cần animate position/size change, không thêm vào mọi element.
// ✅ variants ngoài component — stable reference
const cardVariants = { hidden:{opacity:0}, visible:{opacity:1} };
function Card() {
  const shouldReduce = useReducedMotion();
  return <motion.div variants={shouldReduce ? {} : cardVariants} />;
}
⚡ MotionValue không trigger re-render
useMotionValue và useTransform cập nhật trực tiếp DOM style mà không qua React render cycle — đây là lý do scroll-linked animations mượt.
⚡ transform thay left/top
Framer Motion mặc định dùng transform cho x/y — GPU composite layer. Tránh animate top/left trực tiếp.
⚡ LazyMotion + domAnimation
Dùng LazyMotion + domAnimation để chỉ load features cần thiết — giảm bundle size đáng kể (từ ~34kb → ~18kb).
⚡ will-change tự động
Framer Motion tự động set will-change: transform khi detect có animation — bạn không cần làm thủ công.
// LazyMotion: giảm bundle size
import { LazyMotion, domAnimation, m } from 'framer-motion';
<LazyMotion features={domAnimation}>
  <m.div animate={{ x:100 }} />  // dùng m.div thay motion.div
</LazyMotion>
