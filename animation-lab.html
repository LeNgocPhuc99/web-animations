05 Stagger Animation

Stagger = delay tăng dần giữa các phần tử. Tạo cảm giác "sóng" rất tự nhiên. Trong CSS thuần, dùng animation-delay. GSAP có built-in stagger.

bar chart stagger
/* CSS: delay tăng theo index */
.bar:nth-child(n) { transition-delay: calc(n * 0.06s); }
/* GSAP: */  gsap.to('.bar', { stagger: 0.06, scaleY: 1 });
06 Scroll-triggered Animation

Dùng IntersectionObserver để trigger animation khi element vào viewport. GSAP ScrollTrigger làm điều tương tự nhưng mạnh hơn nhiều.

↓ cuộn xuống trong khung này

Concept 01 — Translate + Fade

Element trượt vào từ trái, đồng thời opacity tăng từ 0 lên 1.

Concept 02 — Staggered reveal

Mỗi card có delay khác nhau, tạo cảm giác từng item xuất hiện theo lượt.

Concept 03 — Spring easing

Dùng cubic-bezier(0.34, 1.56, 0.64, 1) để có hiệu ứng overshoot nhẹ.

Concept 04 — Intersection threshold

Có thể cấu hình bao nhiêu % element vào viewport thì trigger animation.

Concept 05 — Once or repeat

Có thể animate một lần (removeObserver sau khi trigger) hoặc mỗi lần scroll.

const obs = new IntersectionObserver((entries) => {
  entries.forEach(e => {
    if (e.isIntersecting) e.target.classList.add('visible');
  });
}, { threshold: 0.2, root: scrollContainer });
07 Performance — GPU vs CPU

Chỉ transform và opacity chạy trên GPU compositor. Animate left/top/width sẽ trigger layout reflow, gây jank ở 60fps.

🔴 bad — animate left (layout reflow)
left CPU
🟢 good — animate transform (GPU composite)
transform GPU
/* 🔴 Tránh */ @keyframes { from { left: 0 } to { left: 100% } }
/* 🟢 Dùng */ @keyframes { from { transform: translateX(0) } to { transform: translateX(300px) } }
